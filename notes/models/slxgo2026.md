# SLxGO / SLxGO+ (2026)

**Source:** [bioRxiv preprint](https://doi.org/10.64898/2026.07.31.742101),
[official code](https://github.com/sshameer/SLxGO2026), and
[additional data](https://doi.org/10.5281/zenodo.19915131). The code is in
`external/models/slxgo2026` (ignored by git).
The Zenodo `Large_files.zip` (SHA-256
`04606ab021aff55e6f969468f758fb93c26a2c9215d971e4e695fd38a65f06ea`)
was inspected: it contains the 9.84 GB full pair-feature table, a 1.84 GB
BioBERT embedding input, the 19.9 MB GO-PCA vectors already in the code
repository, and cell-line expression. It supplies no GO evidence-code map or
SL-free replacement for the network branch.

The released *full* classifier combines pairwise 50-dimensional GO BioBERT
PCA embeddings with 49 network features generated by an ANN. That ANN was
trained to imitate SLant feature files whose source includes genetic
interaction information. The released SL classifiers are also trained on
external SL pair labels. Neither checkpoint can be ranked in SLB as-is.

`scripts/models/slxgo2026/run.sh` evaluates a named **GO-PCA branch**:
the authors' released GO BioBERT PCA vectors, both gene orders, and their
HistGradientBoosting classifier family, refitted on SLB train pairs with
fixed hyperparameters. The network ANN is omitted. We leave this diagnostic
unranked because the authors' PANTHER/GO annotation file does not provide
evidence codes needed to exclude IGI; the released vector cannot be
retrospectively evidence-filtered. It is an ablation, not the full SLxGO.
