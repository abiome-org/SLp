to test contracts and contain no biological measurements. Real datasets and
derived arrays remain untracked OMF artifacts.

SLp-1.1 engineering prototype. It does not satisfy the current corpus-audit,
held-roster, target-free query, or protected-truth boundaries. Its former OMF

snapshots as evidence for the sparse candidate. The files remain only so prior
