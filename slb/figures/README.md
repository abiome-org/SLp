# Synthetic lethality benchmark figures

Rebuild the SVG, PNG and PDF files with:

```bash
uv run python figures/make_figures.py
```

The plotting code reads SLB result JSON from `results/models/slb/`,
the ancestry audit and matched-benchmark JSON from `reference/`, and a literal transcription of
Table 3 in the cited 2024 paper. The test results are regenerated by the
model adapters and `slbench eval`; rebuild the ancestry audit first with
`SLB_BENCH=data/slb uv run python scripts/audit_ancestry.py`,
then `SLB_BENCH=data/slb uv run python scripts/benchmark_ancestry.py`.

## Captions

1. **[Gene exposure](01_gene_exposure.svg).** The same 12 methods are compared
   under CV1 (both genes seen in *other* training pairs), CV2 (one unseen) and
   CV3 (both unseen). The median F1 drops from 0.861 to 0.669; median NDCG@10
   drops from 0.239 to 0.002. F1 = 0.667 is attained by an all-positive
   classifier on the paper's 1:1 data. These are published results on
   SynLethDB and random negatives, not SLB scores. Tested pair labels are
   withheld in all three CV settings. Source: [Feng et al. 2024, Table 3](https://pmc.ncbi.nlm.nih.gov/articles/PMC11491473/#Tab3).
2. **[SLB held-out test](02_slb_held_out_test.svg).** SLB family-held-out
   fitness-balanced AUROC, with family-bootstrap 95% intervals, beside the
   human component. Open circles identify human-only methods, which tie at
   0.500 on budding and fission yeast; the diamond identifies PAGAN, which
   scores human and budding yeast only. Comparison is descriptive: the top
   confidence intervals overlap. Source: the local `*_test.json` score files
   and the [leaderboard](../README.md#leaderboard).
3. **[Species signal](03_species_signal.svg).** Per-species SLB test scores
   for models that score all three headline species. Every cell uses the same
   fitness-balanced, within-context metric. Source: the same score files.
4. **[Human cell-line ancestry](04_human_ancestry.svg).** Frozen test predictions
   evaluated within AFR-, EAS- and EUR-annotated cell lines. Whiskers are 400
   gene-family bootstrap intervals. Genetic ancestry estimates come from
   [Dutil et al. 2019](https://pubmed.ncbi.nlm.nih.gov/30894373/) through
   Cellosaurus; one EAS line uses a reported population instead. The figure
   is a cell-line screen audit, not a patient outcome comparison. Source:
   [`reference/ancestry_audit.json`](../reference/ancestry_audit.json).
5. **[Matched ancestry support](05_ancestry_support.svg).** Exact cancer-site, source-set and
   gene-pair overlap exposes the number of evaluable donor lines behind the retrospective
   ancestry comparison. The red dashed line is only the five-line floor; the protocol also
   requires pair and positive counts, donor-disjoint training and guide-variant QC. Source:
   [`reference/ancestry_benchmark.json`](../reference/ancestry_benchmark.json).
6. **[Matched line scores](06_ancestry_line_scores.svg).** Frozen Dev Rank Ensemble AUROC separately
   in each cell line of the matched panels. Diamonds show equal-cell-line block means.
   These are diagnostic points; the donor-adequacy gate withholds population intervals
   and fairness verdicts. Source: [`reference/ancestry_benchmark.json`](../reference/ancestry_benchmark.json).

These figures support the narrower observation that current methods often
depend strongly on prior exposure to the evaluated genes. A CV1→CV3 gap by
itself does not prove that a method learned no transferable gene relationships,
and the 2024 F1/NDCG values cannot be numerically compared with SLB AUROC.
